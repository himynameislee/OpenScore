# OpenScore brand assets

*The attacker's view, open to everyone.*

| File | Use |
|---|---|
| `openscore-logo-light.svg` / `openscore-logo-dark.svg` | Logo (mark + wordmark) for light / dark backgrounds |
| `openscore-logo-light@2x.png` / `openscore-logo-dark@2x.png` | Same, PNG (transparent), where SVG isn't supported |
| `openscore-mark-light.svg` / `openscore-mark-dark.svg` | Mark only, for light / dark backgrounds |
| `openscore-mark-mono.svg` | One-color mark (`currentColor`), for single-color printing or embossing |
| `favicon.svg` | Small-size mark (4 segments); follows the browser's light/dark theme |
| `openscore-avatar-512.png` | Square avatar (social / org profile) |
| `social-preview.png` | 1280×640 repository social preview (Settings › General › Social preview) |

## The mark

An "O" of eight ring segments, one per scoring factor, shading from red through purple to
blue (red team + blue team = purple team), around a square evidence block. Keep the gaps
between segments visible at every size; below 32 px use `favicon.svg` (4 segments).

Don't recolor individual segments, add effects, rotate the mark, or place the full-color
mark on busy or mid-tone backgrounds; use the mono mark there.
